# Changelog

- Deterministic Go CLI with `init`, `doctor`, `validate`, `prompt`, `profiles`, and `integrations` commands.

- Product, feature, architecture, UX, implementation, and release-evidence artifacts.
- Third-party integration registry with license and conflict guidance.
- Preventive hook for secret access and destructive commands.
- Unit tests, plugin validation, guard tests, CI, policies, and runbooks.
