Review the proposed UX against the feature contract and existing product baseline. Evaluate user intent, information architecture, hierarchy, primary action clarity, state coverage, accessibility, responsive/native behavior, data visualization, consistency, and signs of generic AI design. Distinguish blockers from taste. Do not edit files. Return prioritized findings and a concrete definition of what a strong corrected design would look like.
