# Roadmap

## v0.1 — Foundation

- [x] deterministic Go CLI;
- [x] project profiles and templates;
- [x] Claude plugin and local marketplace;
- [x] product, architecture, UX, delivery, and readiness skills;
- [x] specialist subagents;
- [x] external integration registry;
- [x] preventive guard hook;
- [x] tests, CI, policies, and runbooks.

## v0.2 — Traceability

- [ ] parse requirement IDs and detect orphan requirements;
- [ ] validate ADR/UX/plan references;
- [ ] generate requirement-to-test coverage report;
- [ ] produce a concise owner decision packet;
- [ ] add brownfield baseline inventory command.

## v0.3 — Controlled runtime

- [ ] explicit run state machine;
- [ ] isolated worktree creation and cleanup;
- [ ] safe command allowlist per project profile;
- [ ] model/provider routing without changing product truth;
- [ ] max-turn, retry, token, and monetary budgets;
- [ ] resumable runs and JSONL tool-call audit;
- [ ] no generic shell in unattended mode.

## v0.4 — GitHub delivery

- [ ] task/issue ingestion;
- [ ] draft PR creation;
- [ ] CI evidence collection;
- [ ] requirement-linked review findings;
- [ ] preview URL and screenshot/device evidence;
- [ ] explicit owner acceptance gate.

## v0.5 — Evaluations

- [ ] golden scenarios for SaaS, dashboard, and Expo mobile;
- [ ] requirement-retention evaluations;
- [ ] architecture option-quality evaluations;
- [ ] UI-state and accessibility evaluations;
- [ ] token/cost regression budgets;
- [ ] third-party integration compatibility matrix.

## Non-goals before 1.0

- fully autonomous production deployment;
- unlimited agent swarms;
- automatic purchasing/provisioning of third-party services;
- legal/compliance decisions without qualified human review;
- claiming guaranteed defect-free software.
